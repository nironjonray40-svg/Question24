# 🎓 প্রশ্ন ব্যাংক ও স্বয়ংক্রিয় প্রশ্নপত্র প্রস্তুতকারক (Question Bank & Exam Generator)
### আলহেরা এডুকেয়ার হোম উচ্চ বিদ্যালয়

জাতীয় শিক্ষাক্রম ও পাঠ্যপুস্তক বোর্ড (NCTB) কারিকুলাম অনুযায়ী শ্রেণি, বিষয়, অধ্যায় ও পাঠভিত্তিক প্রশ্ন সংরক্ষণ এবং তাৎক্ষণিক পরীক্ষার প্রশ্নপত্র তৈরি করার একটি ফুল-স্ট্যাক ওয়েব অ্যাপ্লিকেশন।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Features):

1. **কেন্দ্রীয় প্রশ্ন ব্যাংক (Central Question Bank):**
   - শ্রেণিবিন্যাস: **শ্রেণি (Class) ➔ বিষয় (Subject) ➔ অধ্যায় (Chapter) ➔ পাঠ/টপিক (Topic)**
   - ৩টি ভিন্ন প্রশ্ন ফরম্যাট সমর্থন:
     - **বহুনির্বাচনি প্রশ্ন (MCQ):** ৪টি বিকল্প অপশন (ক, খ, গ, ঘ), সঠিক উত্তর ও সমাধান।
     - **সংক্ষিপ্ত প্রশ্ন (Short Questions):** সংক্ষিপ্ত প্রশ্ন ও মডেল উত্তর।
     - **সৃজনশীল প্রশ্ন (CQ):** দৃশ্যকল্প/উদ্দীপক (Stem) এবং ৪টি উপ-প্রশ্ন (ক-জ্ঞানমূলক [১], খ-অনুধাবনমূলক [২], গ-প্রয়োগমূলক [৩], ঘ-উচ্চতর দক্ষতামূলক [৪])।

2. **প্রশ্নপত্র প্রস্তুতকারক (Question Paper Builder):**
   - ডায়নামিক ক্যাস্কেডিং ড্রপডাউন (শ্রেণি ➔ বিষয় ➔ অধ্যায়)।
   - লাইভ সিলেকশন কার্ট এবং রিয়েল-টাইম মোট নম্বর ও প্রশ্ন গণনা।
   - স্কুলের নাম, পরীক্ষার নাম, সময়, পূর্ণমান ও সাধারণ নির্দেশনা কাস্টমাইজেশন।

3. **মুদ্রণ ও PDF এক্সপোর্ট (NCTB Formatted Print & PDF):**
   - বোর্ড প্রশ্নপত্রের আদলে প্রফেশনাল লেআউট।
   - বিভাগভিত্তিক বিন্যাস ('ক' বিভাগ: MCQ, 'খ' বিভাগ: সংক্ষিপ্ত, 'গ' বিভাগ: সৃজনশীল)।
   - ব্রাউজার থেকে সরাসরি পরিচ্ছন্ন ও মার্জিন-নিয়ন্ত্রিত PDF ডাউনলোড / প্রিন্ট সুবিধা (UI ও বাটন ছাড়া)।

4. **সংরক্ষিত প্রশ্নপত্র তালিকা (Saved Papers):**
   - পূর্বে তৈরি করা প্রশ্নপত্র ডাটাবেজে সংরক্ষণ ও পরবর্তীতে যেকোনো সময় পুনরায় প্রিন্ট করার সুবিধা।

## 🚀 লোকাল সার্ভারে চালানোর নিয়মাবলী (How to Run Locally):

### অপশন ১: এক ক্লিকে চালানো (Windows)
ফোল্ডারে থাকা `run.bat` ফাইলটিতে ডাবল ক্লিক করুন।

### অপশন ২: টার্মিনাল বা কমান্ড প্রম্পটের মাধ্যমে
১. ডিপেন্ডেন্সি ইনস্টল করুন (যদি ইতিপূর্বে না করা থাকে):
```bash
pip install -r requirements.txt
```

২. সার্ভার চালু করুন:
```bash
python app.py
```

৩. এরপর আপনার যেকোনো ব্রাউজার (Google Chrome / Edge) ওপেন করে এই লিংকে প্রবেশ করুন:
👉 **[http://127.0.0.1:5000](http://127.0.0.1:5000)**
